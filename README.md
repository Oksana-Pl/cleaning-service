# Cleaning Website

Это рабочая папка сайта. Все дальнейшие изменения вносим здесь.

- `index.html` — структура страницы; секции отмечены комментариями.
- `style.css` — оформление и адаптивные правила для компьютера, планшета и телефона.
- `script.js` — мобильное меню, сравнение до/после и подготовка заявки.
- `images/` — фотографии и видео, используемые страницей.

Откройте эту папку целиком в Visual Studio Code. Для просмотра откройте `index.html` в браузере или через Live Server. Установка библиотек не требуется.

Для пересылки отправляйте всю папку или ZIP-архив: HTML использует соседние CSS, JavaScript и изображения.

Название FRESH пока рабочее. Форма составляет и скачивает текст заявки локально; отправка в компанию не подключена. Изображения сгенерированы, сравнение обозначено как иллюстрация.


Hero video loads locally from `images/hero-video.mp4`. The original photograph remains as a fallback and poster. Pause/play and reduced-motion support are included.
